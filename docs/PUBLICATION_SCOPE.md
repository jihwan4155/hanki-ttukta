## 보존 및 제외 기준

README 두 개의 내용과 모든 이미지 참조 경로는 원본 그대로 보존했습니다. README의 실행 안내는 원래 프로젝트에 대한 설명이며, 이 저장소에는 실행에 필요한 소스와 설정 파일이 포함되어 있지 않습니다.

README에서 사용하는 로고만 `frontend/src/assets/brand/logo.png`에 포함했습니다. 해당 경로의 다른 애플리케이션 파일은 이전하지 않았습니다.

코드 및 Git 로그 캡처가 섞여 있는 `결과_스크린샷` 폴더와 실행용 하위 폴더의 개발 안내서는 이전하지 않았습니다.

공개용 파일만 담은 새 Git 기록으로 구성했으며, 과거 커밋과 `HISTORY` 폴더는 포함하지 않았습니다. Word 보고서에서 개인정보가 보이는 프로필 화면 두 개는 이미지 원본까지 제거했습니다. 원본 문서에 기록된 테스트 결과는 개발 당시의 기록이며, 이번 문서 이전 작업에서 애플리케이션 테스트를 다시 실행한 결과가 아닙니다.
